# SKY BARONESS — 皇牌空战

浏览器里的皇牌空战(Ace Combat)风格 3D 空战游戏。纯 [three.js](https://threejs.org)(WebGL,已本地 vendored,离线可玩),地形、海洋、天空、音效全部程序化生成。玩家座机为**真实 F-14 Tomcat 模型**(`assets/F14Tomcat.glb`,约 3.4MB,缺失时自动回退到程序化战机);敌机与其余元素仍为程序化生成。

## 运行

需要通过本地 HTTP 服务器打开(ES Module 限制,不能直接双击 index.html):

```bash
cd plan_A
python serve.py            # 自带 no-cache 头,刷新即得最新代码
# 浏览器打开 http://127.0.0.1:8421
```

或 `npx serve .`(开发时推荐 serve.py,避免浏览器缓存旧模块)。

### 雷达弹与红外弹

**R 键切换弹种,X 键即时锁定/取消,空格发射(需先预热)。**

发射流程:**预热(1s,ALT 发起;冷态按空格也可)→ 8s 保温窗口 → 空格发射**。ALT 是唯一的取消方式;条件不满足按空格无效并在准星下方提示;切换弹种清空预热。

| | 红外弹 (IR) | 雷达弹 (RADAR) |
|---|---|---|
| 挂载 | 6 发(5.5s/发回充) | 4 发(8s/发回充) |
| 锁定 | 可选:X 即时锁定 **20km**(雷达仅作引导),或导引头自动咬定热源(5.2km) | X 即时锁定 **20km**(±8° 篮) |
| 发射条件 | 已预热 且(导引头咬住热源 或 已锁定) | 已锁定 且 已预热 |
| 弹速/转向 | 880 / 3.4 | 780(更慢)/**2.5**(更钝) |
| 伤害 | 60(敌) | **80**(敌)/55(你) |
| 规避方式 | 热诱弹(90/50/20 方位概率) | **箔条 + 39 机动 + 地形遮挡** |
| 被骗后 | 盲飞 1.8s 可能重捕 | 纯三九/遮蔽断锁:盲飞 2.5s 后**主动重扫可能复锁**;**配合箔条的断锁才永久** |

**120° 前锥包络**:机头前方 ±60°。雷达锁定的维持和红外弹的发射都必须在锥内——按 X **获取**锁定仍需目标落在引导圈 ±8° 头瞄篮筐内(套准才锁得上),但**锁上之后**目标只要还在锥内就不脱锁。**出锥不再立刻断锁**:目标框闪烁并显示 2 秒倒计时(CONE — 脱锁 x.xs),期间锁定保留,回到锥内即恢复;**但锥内才是发射门**——出锥期间发射被拒(提示"目标出锥 · 禁射"),红外弹自行咬住的热源不受此限。倒计时归零才断锁。死亡/超 20km 仍是立即断锁;雷达弹**断锁即熄火**,断锁后要重新预热。目标偏离机头 50° 起目标框变琥珀色、56° 起红色闪烁并标注 CONE(屏幕外则边缘箭头变色)——那是即将出锥断锁的警告。

### 拟真模式 · 雷达扫描搜索(War Thunder 式)

拟真模式下目标获取不再依赖距离门,而是**完全由雷达扫描驱动**(街机模式一切照旧):

- **HUD 全面门控**:未被雷达扫到**且不在目视发现圈内**的敌机——雷达盘无光点、无目标框/距离读数/屏外箭头、X 无法锁定;3D 机体模型仍肉眼可见(靠眼睛找机)。已探测(雷达扫描或目视)未锁定的目标显示小菱形+距离(屏外时显示暗青色方位箭头),完整目标框只属于 STT 锁定目标。
- **目视发现圈(3 km / 正后方 1.7 km)**:距本机 **3 km** 内的敌机无需雷达扫描或锁定即被目视**持续发现**——3D 视图实时显示小菱形+距离与屏外方位箭头(位置每帧更新,不淡出);仅**正后方(尾轴±45°锥)**目视距离缩短为 **1.7 km**(机身遮挡视线)。目视发现**不上雷达盘**(雷达盘只显示雷达扫描光点);目视目标的锁定仍走套篮通道(±8°/20 km 头瞄直接锁定)。
- **扇区扫描**:天线在机头 **±60°(宽)/±20°(窄)** 扇区内往返摆动(N 键切换,60°/s),光点只在扫描线**扫过目标方位**的瞬间刷新,其余时间停在**上次刷点位置**并逐渐变淡,约 4 秒未重扫即消失。机尾方向是盲区——必须转向搜索。
- **100km 仪表量程**:扫描作用距离 100km(全战场),限制因素只有扇区而不是距离;雷达量程 M 键增加 **40km 档**用于显示远距目标。
- **STT 单目标跟踪(X 双通道)**:**①目视通道**——目标进入 **20 km** 内且套进引导圈 ±8° 篮,**头瞄直接锁定**,无需雷达扫描(把准星套过去就相当于头瞄锁定);锁上的瞬间雷达随动转为 STT 跟踪,此后按统一规则维持。**②雷达通道**——空篮时 X 锁定最靠机头的**已扫描**目标(无需篮筐——天线扫得到的就能跟);**F 键在已探测目标中循环切换**(绝不掉锁)。任一通道锁定后天线停止搜索、钉死目标(STT),其他光点停止刷新并淡出——真战斗机雷达的行为。锁定维持统一为 120° 锥 + 2 秒出锥宽限,距离不设上限(目视锁定后目标拉开到 20 km 外不掉锁)。
- **主动弹 · 20km 弹载雷达开机**:雷达弹锁定后**任意距离可发射**(发射门只看锁定+预热)。发射后中段按装订目标惯性/数据链飞行——**导引头未开机,三九/箔条/地形全部无效**;距目标 20km 时弹载雷达开机(PITBULL,HUD 提示+公告),此后才进入常规雷达环境逻辑(三九/箔条/多径可断锁,主动重扫距离同步放大到 20km)。发射后即可自由机动,无需持续照住目标。**运动学射程**:动力段 12.2s(燃尽 ~1120-1360 m/s 随高度),90s 自毁——直线弹道最大射程**中低空 ~43km / 高空(10-14km)~52-61km**,配合 100km 雷达扫描构成完整 BVR 交战;机动规避会显著吃掉能量与射程。


**红外导引头(完全物理)**:按 ALT(或冷态空格)预热后,引导圈外围出现**闪烁红色圆框**;±8° 篮内出现**最近的热源**(敌机或燃烧中的热诱弹——**诱饵也是热源**!咬定同样只在锥内)时圆框变**常亮**,才可以发射,咬住的目标上会标红色菱形。

**外圈(LIM 120°,真实投影)**:始终按真实几何画,屏外部分不画。**冷态(未预热未锁定)只画离瞄准方向最近的一段弧**(±40°)——平飞时它在屏幕外约 3°,瞄准一旦拉离机头(战斗机动)就会入画,提示你正在接近的锁定边界;**预热中/已热或已锁定则画出完整的可见环**。接近锥缘时环与目标框一起变琥珀/红色闪烁。

**20km 锁定与弹体射程**(街机):雷达弹锁定距离 20km(敌机生成距离即可锁定、提前预热),但弹体极限飞行约 12.5km(16s 自爆)——超远距锁定用于态势感知,实际发射仍需拉进距离,否则浪费弹药。拟真模式下此段由上一节的雷达扫描/STT/主动弹规则取代(锁定不限距、发射不限距、20km 弹载雷达开机)。敌机雷达锁定距离保持 10km(敌方火控保守)。发射时**热源优先于雷达锁定**:即使有 X 锁引导,锥内同时出现锁定目标和更近的热源(含诱饵),导弹依旧扑向热源——追诱饵的导弹在诱饵烧尽(2.6s)后盲飞 1.8s 再尝试重捕任何飞机。有雷达锁定而无热源时,红外弹由雷达引导发射。

**39 机动与箔条的正确关系**:箔条**不会直接骗走雷达弹**——它的作用是**放宽三九机动的容差**并**固化断锁**。没有箔条时必须做标准梁位(导弹在正侧方 ±17° 内)持续 0.9 秒才脱锁;撒了箔条后容差放宽到 ±33°(懒梁位/48 方向也行)且只需 0.7 秒。**纯三九/地形遮蔽造成的脱锁是暂时的**:导弹盲飞约 2.5 秒后转为主动扫描(±45° 锥、9 公里内每 0.5 秒重扫),不保持梁位或没逃出其扫描锥就会被复锁;只有断锁瞬间 1.5 公里内有箔条云的脱锁才是永久。第 2 波起约半数敌机携带雷达弹(同样 10km 锁定,同样的箔条规则),HUD 底部 **RWR 威胁环**显示雷达导弹方位距离(盲飞期红点降级为黄点,复锁后恢复),来袭时弹出红色 RADAR 告警——撒箔条固化 + 转梁位、或钻山沟后拉开几何。相机在转弯时**不随机体倾斜**(地平线始终水平)。

### 热诱弹(方向性干扰 + 持续重掷)

导弹来袭时投放热诱弹,单次判定成功率取决于**导弹相对你机体的方位**:前半球 90%、侧面 50%、后半球 20%。**诱弹在燃烧期(2.4s)每 0.55s 持续重掷**(每发最多补掷 2 次)——按一次投 3 发,迎头/侧面基本必骗,尾追导弹也有很高概率被骗但盲飞 1.8s 后可能重新咬回,必须配合机动。被诱骗的导弹可能重新锁定**任何**飞机(包括误伤敌机)。弹药 90 发、每 5 秒回充 1 发(敌机 18 发)。

**敌机发射导弹的规则**:机头锥内持续锁定 1.15 秒 + 导弹头预热 1 秒(总 2.15 秒预警窗口)才发射——你的头瞄锁定是即时的,这就是飞行员的火控优势。锁定期间你的 HUD 显示琥珀色"⚠ 敌方锁定中",预热阶段显示"⚠ 敌方预热中"(发射后变红色 MISSILE 告警+屏幕红边)。敌机发射的导弹在你视角没有发射音。

**防空阵地(地图边界)**:作战半径 14km 的圆周海面上均匀布置 **6 座不可摧毁的防空阵地**,每座从四种造型中随机生成——**神盾武库舰**(160m,VLS 井盖阵+相控阵)、**钻井平台要塞**(55m 井架+旋转抛物面雷达)、**圆顶巨兽炮台**(炮塔会转向来犯者)、**海岸 SAM 海堡**(钢筋混凝土+斜轨热发射),雷达旋转、红色航空灯闪烁。接近边界(**85% 半径起**)HUD 显示琥珀色"接近战区边界—建议转向"+剩余距离;越界后仍有 **800m 宽限**纵深阵地才开火——来得及掉头。开火后:发射前**舱盖开启、弹体从发射井顶出再点火**(闪光+烟柱),**一组 5 发、每秒 1 发**,打完 4 秒补组。防空弹**动力无限**(不会自爆)、**转向 4.5/s 且完全无视热诱弹/箔条——不可规避**,命中 60 伤害。回到界内阵地即停火,但已升空的导弹会继续追击。越界 15 秒的强制坠毁规则仍然保留作为最终保险。所有来袭导弹都有**旋转菱形标识**(屏内跟弹、出屏贴边缘),与 MISSILE/RWR 告警互补。

和 War Thunder 一致的核心机制:**引导圈(鼠标指向)锚定在世界空间,而视角也锚定在鼠标指向上**——鼠标位移同时旋转世界瞄准方向和视角;相机沿瞄准轴挂在机体后方,地平线基本保持水平,飞机自己在画面里压坡度去追引导圈。鼠标停住后机头收敛对齐、自动改平直飞。开局点击画面会请求指针锁定(获取无限相对移动;ESC 释放并自动暂停)。X 即时锁定敌机、ALT 预热导弹头(1s)、空格发射追踪导弹,持续大坡度可甩掉来袭导弹。飞出作战空域 15 秒任务失败,撞地坠毁。

## 气动模型(全拟真)

敌我共用同一套 6 自由度刚体气动核心(`src/units/flightmodel.js`):

- **力矩操控**:舵面产生角加速度而非角速率,旋转带惯性与气动阻尼
- **速度独立矢量**:机头≠航迹,迎角 α 与侧滑 β 自然涌现,升力垂直来流
- **升力曲线**:CL=5.2/rad 线性段 + 15° 后软失速衰减;升致阻力 ∝CL²
- **FBW 软保护**:±14° 迎角限制器(对任何输入源生效)+ 低速推杆器(150m/s 以下),失速=掉高度掉速度+机头下沉,推杆即改出,不会进入不可控螺旋
- **G 限制**:instructor 拉杆受 16G 限制(高速时迎角上限自动收紧)
- **能量机动**:拉杆掉速、俯冲增速、爬升换高度;空气密度随高度衰减推力与升力
- HUD 显示 **G 值与迎角 α**,航迹标记为真实速度矢量(与机头分离)

- `?t=N` — 确定性冻结帧:模拟 N 秒后渲染一帧(用于截图验证),冻结模式在 4.2/9.0/13.5s 定点自动发射导弹
