# SKY BARONESS — 皇牌空战

浏览器里的皇牌空战(Ace Combat)风格 3D 空战游戏。纯 [three.js](https://threejs.org)(WebGL,已本地 vendored,离线可玩),地形、海洋、天空、音效全部程序化生成。玩家座机为**真实 F-14 Tomcat 模型**(`assets/F14Tomcat.glb`,约 3.4MB,缺失时自动回退到程序化战机);敌机与其余元素仍为程序化生成。

## 运行

需要通过本地 HTTP 服务器打开(ES Module 限制,不能直接双击 index.html):

```bash
cd plan_A
python -m http.server 8421
# 浏览器打开 http://127.0.0.1:8421
```

或 `npx serve .`。

## 操作(战雷式鼠标瞄准 · Mouse Aim)

| 输入 | 功能 |
|---|---|
| 鼠标移动 | 旋转**世界锚定**的引导圈,视角跟随鼠标指向 — 机头自动追圈 |
| 左键 | 机炮 |
| 右键 | 发射导弹(需锁定) |
| **中键** | **干扰弹**(热诱弹+箔条自动识别,可在键位设置中改) |
| **R** | 切换红外弹/雷达弹 |
| **X** | **头瞄锁定**:引导圈(鼠标指向)对准敌机后按 X 尝试锁定(±8° 篮,锁定需保持目标在视线 ±25° 内 1.15s) |
| W / S | 推杆俯冲 / 拉杆爬升(手动覆盖) |
| Shift / Ctrl 或 滚轮 | 油门增减 |
| A / D | 手动横滚(临时覆盖 instructor) |
| Q / E | 方向舵 |
| **C 长按** | **自由视角**:按住拖动鼠标环视机体四周,松开自动回位(期间瞄准方向不动) |
| V | 切换视角档位(近/中/远) |
| Z | 放大(约 3 倍,再按取消;瞄准灵敏度随倍率自动变细) |
| P / ESC | 暂停(ESC 释放鼠标,点击画面恢复) |
| 回车 | 开始 / 重开 |

**所有键位可在左下角「键位设置」中自由重绑**(点击按键框→按下新键,持久保存)。

### 雷达弹与红外弹

**R 键切换弹种,X 键循环锁定目标。**

| | 红外弹 (IR) | 雷达弹 (RADAR) |
|---|---|---|
| 锁定 | 25°锥/5.2km/1.15s | 25°锥/**10km**/1.15s |
| 弹速/转向 | 880 / 3.4 | 780(更慢)/**2.5**(更钝) |
| 伤害 | 60(敌) | **80**(敌)/55(你) |
| 规避方式 | 热诱弹(90/50/20 方位概率) | **箔条 + 39 机动 + 地形遮挡** |
| 被骗后 | 盲飞 1.8s 可能重捕 | **永久脱锁直飞** |

**39 机动与箔条的正确关系**:箔条**不会直接骗走雷达弹**——它的作用是**放宽三九机动的容差**。没有箔条时必须做标准梁位(导弹在正侧方 ±17° 内)持续 0.9 秒才脱锁;撒了箔条后容差放宽到 ±33°(懒梁位/48 方向也行)且只需 0.7 秒。**地形遮挡**(视线穿山)任何时候都直接脱锁。第 2 波起约半数敌机携带雷达弹(同样 10km 锁定,同样的箔条规则),HUD 底部 **RWR 威胁环**显示雷达导弹方位距离,来袭时弹出红色 RADAR 告警——撒箔条辅助 + 转梁位、或钻山沟。相机在转弯时**不随机体倾斜**(地平线始终水平)。

### 热诱弹(方向性干扰 + 持续重掷)

导弹来袭时投放热诱弹,单次判定成功率取决于**导弹相对你机体的方位**:前半球 90%、侧面 50%、后半球 20%。**诱弹在燃烧期(2.4s)每 0.55s 持续重掷**(每发最多补掷 2 次)——按一次投 3 发,迎头/侧面基本必骗,尾追导弹也有很高概率被骗但盲飞 1.8s 后可能重新咬回,必须配合机动。被诱骗的导弹可能重新锁定**任何**飞机(包括误伤敌机)。弹药 90 发、每 5 秒回充 1 发(敌机 18 发)。

**敌机发射导弹与你遵守同一规则**:机头锥内持续锁定 1.15 秒才能发射,锁定期间你的 HUD 会显示琥珀色"⚠ 敌方锁定中"告警(发射后变红色 MISSILE 告警)。敌机发射的导弹在你视角没有发射音。

和 War Thunder 一致的核心机制:**引导圈(鼠标指向)锚定在世界空间,而视角也锚定在鼠标指向上**——鼠标位移同时旋转世界瞄准方向和视角;相机沿瞄准轴挂在机体后方,地平线基本保持水平,飞机自己在画面里压坡度去追引导圈。鼠标停住后机头收敛对齐、自动改平直飞。开局点击画面会请求指针锁定(获取无限相对移动;ESC 释放并自动暂停)。锁定敌机后右键发射追踪导弹,持续大坡度可甩掉来袭导弹。飞出作战空域 15 秒任务失败,撞地坠毁。

## 地形 · 天气 · 昼夜

- **四生物群系**在同一张地图上分区混合(自然过渡带):温带绿谷 / 沙漠丘陵(含沙纹)/ 火山黑岩 / 雪山高原(山体更高、雪线更低),高度与配色随群系变化
- **8 分钟昼夜循环**:任务从黄金时刻开始,经白昼→黄昏→**夜晚(月光+星空)**→黎明;光照、雾色、海面、云层全部联动
- **五档动态天气**:晴/多云/阴/雨/**雷暴**(闪电+暴雨),60–120 秒自动换档、约 6 秒平滑过渡;影响云量、雾浓度、光线亮度与降雨
- HUD 右上角显示**任务时钟与天气**;海岸线做了深度偏移修复,无 Z-fighting 闪烁

## 气动模型(全拟真)

敌我共用同一套 6 自由度刚体气动核心(`js/flightmodel.js`):

- **力矩操控**:舵面产生角加速度而非角速率,旋转带惯性与气动阻尼
- **速度独立矢量**:机头≠航迹,迎角 α 与侧滑 β 自然涌现,升力垂直来流
- **升力曲线**:CL=5.2/rad 线性段 + 15° 后软失速衰减;升致阻力 ∝CL²
- **FBW 软保护**:±14° 迎角限制器(对任何输入源生效)+ 低速推杆器(150m/s 以下),失速=掉高度掉速度+机头下沉,推杆即改出,不会进入不可控螺旋
- **G 限制**:instructor 拉杆受 16G 限制(高速时迎角上限自动收紧)
- **能量机动**:拉杆掉速、俯冲增速、爬升换高度;空气密度随高度衰减推力与升力
- HUD 显示 **G 值与迎角 α**,航迹标记为真实速度矢量(与机头分离)

## 调试参数
- `?t=N` — 确定性冻结帧:模拟 N 秒后渲染一帧(用于截图验证),冻结模式在 4.2/9.0/13.5s 定点自动发射导弹
- `?debug=1` — 在 `window.__game` 暴露内部状态(供无头测试)

## 架构

| 文件 | 职责 |
|---|---|
| `index.html` | 画布 + HUD 层 + 标题/结算界面 |
| `js/main.js` | 游戏循环、状态机、系统接线、`?t=` 冻结 harness |
| `js/sky.js` | 大气模型:天空穹顶着色器(渐变+太阳+Mie 前向光晕)、fbm 云层、雾、光照 |
| `js/terrain.js` | 岛链高度场(ridge fbm)、顶点色分层、海洋着色器(菲涅尔+太阳光带) |
| `js/jet.js` | 程序化战机建模(机身/三角翼/双垂尾/座舱/加力锥)— 敌机与玩家回退模型 |
| `js/f14.js` | 玩家 F-14 GLB 加载器(锚点/加力锥/舵面驱动,失败回退程序化战机) |
| `js/player.js` | 街机飞行模型(四元数姿态)、追尾相机 |
| `js/enemies.js` | 敌机 AI(巡逻/追击/规避)、波次刷新 |
| `js/weapons.js` | 机炮弹道、锁定导弹(比例导引+近炸)、敌导弹 |
| `js/effects.js` | 粒子池:爆炸/尾烟/拉烟/火花 |
| `js/hud.js` | AC 风格 HUD(2D canvas) |
| `js/audio.js` | WebAudio 程序化音效 |
| `js/utils.js` | 种子 RNG、simplex 噪声、数学工具 |

渲染路径:所有材质输出 scene-linear,`renderer.toneMapping = ACESFilmic` 是唯一输出级(色调映射只做一次);天空、平行光、半球光、雾共享同一太阳方向。
