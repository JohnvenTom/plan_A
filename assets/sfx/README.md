# assets/sfx — 音效素材文件夹

游戏音效文件统一放在这里。当前 `js/audio.js` 是纯程序化合成（WebAudio 实时生成，
零素材依赖）；往本文件夹放入音效文件后，需要在 audio.js 里接入加载与播放
（告诉 ZCode 文件名即可，例如"把 explosion.mp3 接到爆炸事件上"）。

## 命名约定

按游戏事件命名，全小写 + 下划线，与 audio.js 里的方法一一对应：

| 事件方法 | 语义 |
|---|---|
| gun | 机炮 |
| missile_launch | IR 弹发射 |
| radar_launch | 雷达弹发射 |
| explosion | 爆炸 |
| kill | 击坠确认 |
| sonic_boom | 音爆 |
| flare | 抛射干扰弹 |
| lock | 锁定 |
| warm_start / warm_ready / warm_cancel | 导弹预热 |
| seek_bite | 红外导引头咬住 |
| near_miss | 近失弹掠过 |
| hit_ting / hit_taken | 命中提示 / 被击中 |
| engine / wind | 引擎与风声（循环） |

## 格式建议

- 首选 `mp3`（体积小，浏览器全兼容）；需要零延迟的短促音效用 `wav`
- 循环音（引擎/风）确保首尾平滑，避免爆音
- 采样率 44100 Hz，单声道即可（游戏内不做 3D 声像）

## rwr/ — RWR 座舱告警（实机采样）

来自实机 RWR 的 aac 采样。除 New Contact 是每次接触响一次外，其余三个是**持续循环**：
威胁状态存续期间一直响（audio.js 的 rwrUpdate 每帧判定），同一时刻只响优先级最高的
一种（发射 > 硬锁定 > 雷达扫描），声部切换时 20 ms 淡出掐断上一段；采样结尾自带 20 ms
淡出包络，消掉素材硬切产生的尾拍。采样加载后取代原来的程序化哔哔告警；素材缺失或解码
失败时回退到程序化音调（同样的循环槽位），游戏不会静音。

RWR 是独立音量分类（同引擎/风声的模式）：只受"总音量"和设置面板里专用的
"RWR 告警音量"滑条控制（默认 70%），不随"音效"滑条变化。

| 文件 | 状态/事件 | 语义 |
|---|---|---|
| new_contact.aac | 边沿（一次性） | 敌机过 15 km 固定哨戒线（与 HUD 量程无关，离远再进重响）；或贴边接近任一防空阵地 6 km 内 |
| special_contact.aac | 持续（循环） | 被敌雷达扫着（跟踪中、未硬锁定）；SAM 齐射首轮开舱时另作一次性边沿响 |
| radar_lock.aac | 持续（循环） | 被敌雷达载机硬锁定（连续跟踪 ≥1.15 s）期间 |
| missile_launch.aac | 持续（循环，最急促） | 导弹骑脸期间（敌机导弹与防空弹） |

红外弹载机无雷达辐射：扫描/锁定告警不响，直到其导弹发射进入骑脸状态才响发射告警。
